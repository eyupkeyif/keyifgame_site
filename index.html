How we build

Made once, played everywhere.

Going multiplatform is a design choice from day one. These rules shape every project we start.

Fun before features

We prototype the core loop in days and keep only the ideas that make people smile on the first try.

Input-agnostic design

Every action works with touch, mouse, gamepad and motion controllers. No platform gets a second-class port.

A frame budget per device

We set performance targets for the weakest supported phone and test against them every week, so the game runs smoothly on all of them.

Shared saves, shared friends

Cross-save and cross-play where the stores allow it. Start on the bus, finish on the sofa.
